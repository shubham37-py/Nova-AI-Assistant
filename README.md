# 🚀 Nova

Nova is an AI-powered desktop productivity assistant designed for students. It helps users organize daily tasks using voice commands, AI-powered task extraction, reminders, and productivity insights.

---

## ✨ Features

### Current
- ✅ FastAPI Backend
- ✅ SQLite Database
- ✅ SQLAlchemy ORM

### Planned
- 🎤 Voice-to-Task using Faster-Whisper
- 🤖 AI Task Extraction using Ollama
- 🖥️ Electron Desktop App
- 📅 Daily Task Dashboard
- 🔔 Smart Notifications
- 📊 Productivity Analytics
